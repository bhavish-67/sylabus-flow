Syllabus Flow Android-ready offline app

Start with SETUP.md. Set your Tavily API key as the secure `TAVILY_API_KEY` environment variable on a Node.js host, then install the HTTPS site from Android Chrome. Internet is required to search/download external syllabuses; saved syllabuses, plans, progress, and the included library work offline.

The app includes an in-app offline library plus unlimited custom syllabuses. Its optional in-app web search uses Tavily and downloads readable syllabus text into offline storage.
